## 2. 갱신 (분기 1회 권장)

**가장 쉬운 방법** — 프로젝트 폴더의 **`refresh.cmd` 를 더블클릭**하면 됩니다.
(Python 자동 탐색 → 새 사건 감지 → 페이지 재생성 → 검증 → 변경이 있을 때만 push)

명령으로 하려면:

```bash
python _tools/refresh_all.py          # 재생성 + 검증만 (미리보기)
python _tools/refresh_all.py --push   # 검증 통과 시 커밋·푸시
```

| 단계 | 하는 일 |
|---|---|
| 1 | 크론 산출물에서 카드 재추출 + 교정 문장 보강 유지 |
| 2 | **새 사건 자동 감지** — 아직 없는 사건이면 `02-12`, `02-13`… 로 자동 추가 |
| 3 | 02 → 03 → 05 → 04부 **전 페이지 재생성** (TOC는 마지막에 전체 재작성) |
| 4 | `verify_book_repo.py` 게이트 — `OK` 아니면 push하지 않음 |
| 5 | `--push` 이고 **변경이 있을 때만** 커밋·푸시 |

### 의존성 (중요)

1단계는 **크론 산출물 폴더**를 읽습니다:
`%LOCALAPPDATA%\hermes\cron\output\288500143dff\` (AI뉴스·미디어비평 작업)
→ 그 폴더가 없으면 새 카드는 못 만들지만, **`data/*.json`만으로 책 페이지 재생성은 가능**합니다(3단계 이후).

파이썬은 표준 라이브러리만 쓰면 되고, **표지만** Pillow가 필요합니다.
